MA CORE CLAIMS ENGINE — SYSTEM ARCHITECTURE
Owner: Enterprise Architecture
Version: 1.7
Last Reviewed: October 2025

This is SYNTHETIC SAMPLE CONTENT for demonstration purposes only.

OVERVIEW

The Medicare Advantage Core Claims Engine (MA-CORE) is the primary
system supporting claims intake, adjudication, and payment for the
MA line of business. Vendor: Cognizant TriZetto Facets v6.2.

MODULE INVENTORY

  MA-INTAKE-v3.4 — Claims intake and HIPAA 837 parsing
  MA-ADJ-v5.1   — Adjudication engine with rules processor
  PA-MOD-v4     — Prior authorization module
  PROV-MOD-v3.0 — Provider directory and contracts
  PRIC-MOD-v2.7 — Pricing engine and contract terms
  REM-MOD-v2.5  — Remittance advice generation

PA-MOD-v4 CAPABILITIES

The Prior Authorization module supports:
  - PA request creation by providers (via portal or fax-OCR)
  - PA review workflow with clinical decision support
  - PA decision storage and notification
  - PA query API for downstream consumers (Adjudication, Member Portal)

KNOWN LIMITATIONS

PA-MOD-v4 has no interface for ingesting prior authorization records
from external Medicare Advantage organizations. When a new member
enrolls with prior plan PA records, those records must be entered
manually into PA-MOD by member-services staff.

This creates significant operational overhead and risk of data
entry error.

INTEGRATION POINTS

PA-MOD integrates downstream with:
  - MA-ADJ (PA query at adjudication time)
  - Member Portal (PA status display)
  - Provider Portal (PA request submission)

PA-MOD does NOT currently integrate with:
  - External plan PA systems (no transition ingestion)
  - State HIE systems (no automated PA reconciliation)
